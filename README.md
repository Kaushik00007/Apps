# Hello World App  

## Overview  
This is a simple **Hello World** app created using [Thunkable](https://thunkable.com/), a drag-and-drop platform for building mobile applications. The app demonstrates the basic functionality of displaying a "Hello, World!" message and serves as an introductory project for exploring app development.  

## Features  
- Displays a "Hello, World!" message.  
- Clean and user-friendly interface.  
- Built with no-code tools for rapid development.  

## Getting Started  

### Prerequisites  
To view or modify the project, you need a Thunkable account:  
- Sign up at [Thunkable](https://thunkable.com/).  

### Installation  
1. Download the project file from this repository.  
2. Import the file into Thunkable:  
   - Log in to your account.  
   - Click on **Projects** > **Import Project** and upload the file.  

### Running the App  
1. Open the project in Thunkable.  
2. Use the Thunkable Live app on your mobile device to preview the app in real time.  
   - Available on both [Android](https://play.google.com/store/apps/details?id=com.thunkable.live) and [iOS](https://apps.apple.com/app/thunkable-live/id1229483511).  
3. Alternatively, export the project as an APK (for Android) or TestFlight build (for iOS) for deployment.  

## Why Thunkable?  
Thunkable enables rapid app prototyping with a visual drag-and-drop interface, making it ideal for beginners and non-coders.
